# Roadmap

## Version 0.1 - Coaching Skill Foundation

- Define practice and test modes
- Define feedback and session-report structure
- Define privacy and source-label rules
- Publish a reusable, no-API skill skeleton

## Version 0.2 - Personal Topic Bank Preparation

- Review a working copy of the learner's answer bank
- Label real, adapted, model, and unverified material
- Create structured topic entries without changing the raw document
- Test topic reuse across IELTS Parts 1, 2, and 3

## Version 0.3 - Session Report Workflow

- Convert one supplied transcript into a structured report
- Export reports to `data/output`
- Add repeated-error and verb-phrase fields
- Verify that raw files remain unchanged

## Version 0.4 - Local Learning Records

- Add SQLite under `data/database`
- Store sessions, corrections, reusable language, and review status
- Preserve old data through schema migrations and backups

## Version 0.5 - Optional Integration

- Evaluate API-based handoff only if manual transfer becomes too inconvenient
- Keep API keys outside source code
- Compare cost, privacy, and maintenance before selecting a provider
